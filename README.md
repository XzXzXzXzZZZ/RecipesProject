# 📓 Система хранения рецептов

Десктопное WPF-приложение на C# для хранения кулинарных рецептов с возможностью подбора блюд по имеющимся продуктам.

## 🙌 Возможности

- Создание, редактирование и удаление рецептов с пошаговым описанием
- Добавление фото к рецептам и отдельным шагам
- Виртуальный холодильник со списком продуктов
- Подбор рецептов по продуктам из холодильника с учётом «постоянных» продуктов
- Поиск рецептов по названию
- Избранное — быстрый доступ к любимым рецептам
- Экспорт рецепта в PDF для печати
- Оценка сложности рецепта (1–5 звёзд)

## Запуск

1. Склонируйте репозиторий:
git clone https://github.com/XzXzXzXzZZZ/RecipesProject.git
2. Откройте `RecipesProject.sln` в Visual Studio 2022.
3. Убедитесь, что установлен .NET 9 SDK.
4. Запустите проект (`F5`) или соберите exe через **Опубликовать → Папка**.

## Тестирование

Тесты запускаются через **Обозреватель тестов** в Visual Studio (`Вид → Обозреватель тестов`).

Включают:
- Модульные тесты (`RecipeRepository`: добавление, поиск, удаление, избранное)
- Интеграционные тесты (связка Холодильник + Подбор рецептов)
- Ручное системное тестирование по чек-листу (см. документацию)
